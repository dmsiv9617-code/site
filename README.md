# WoodBase — сайт лазерной мастерской

Рабочий фронтенд-прототип: каталог пяти моделей, конструктор с локальной загрузкой рисунка, выбором цвета и аксессуаров, расчётом цены, перелистыванием страниц и корзиной. Мастерская — WoodBase. Иллюстрации, модели и цены демонстрационные.

Визуальная концепция: натуральная фактура дерева, вечерние пейзажи и семейные воспоминания. Изображения в `public/images/hero.png` и `family.png` сгенерированы для прототипа, не являются фотографиями реальных изделий или клиентов мастерской. Гравировки представлены SVG-эскизами. При подготовке магазина к запуску замените концепции фотографиями реальной продукции.

## Разработка

Требуется Node.js 22 или новее.

```sh
cd /workspace/site
npm ci --cache /tmp/site-npm-cache
npm run dev
```

Сборка: `npm run build`. Проверка сборки: `npm run preview`.

Для просмотра без сервера: `npm run export:html`, затем откройте `dist/WoodBase.html` в браузере. Этот файл содержит стили и JavaScript, использует системные шрифты и не требует подключения к сети. Сохранение корзины зависит от поддержки localStorage браузером для локальных файлов.

Корзина хранится в localStorage. Изображения уменьшаются до 600 пикселей и остаются в браузере. Состав заказа скачивается в JSON, включая загруженный рисунок. Это не оформление заказа: сервера, оплаты, доставки и отправки данных в мастерскую пока нет. Не храните в прототипе конфиденциальные изображения на общих устройствах.

Модели, цены, цвета и аксессуары задаются в `src/main.js`, стили — в `src/style.css`. Внешние шрифты Google Fonts необязательны: предусмотрены системные замены.

Следующий этап: реальные данные мастерской и фото, сервер заказов и безопасное хранение загрузок, управление каталогом, проверка доступных интеграций Ozon и подключение согласованного способа оплаты и доставки.
