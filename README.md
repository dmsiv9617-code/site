# WoodBase — сайт лазерной мастерской

Рабочий фронтенд-прототип WoodBase: шесть оформлений из присланных примеров, общий размер обложки 33 × 22 см, корешок 3 см и кольцевой механизм. Переплёт (ручное плетение / дизайнерские болты), цвет и дизайн выбираются независимо. Цены, сроки и комплектация пока по запросу — вымышленные цены удалены. Рисунки обложек иллюстративные, не точные производственные макеты.

Визуальная концепция: крупные альбомы, молочный фон и контрастные секции тёмного дерева. Первый экран разделяет текст и изображение; каталог ведёт к деталям изделия и конструктору, затем к краткому рассказу о мастерской. Маскот помогает только в конструкторе и корзине. Изображения в `public/images/hero.png` и `family.png` сгенерированы для прототипа, не являются фотографиями реальных изделий или клиентов мастерской. Гравировки представлены SVG-эскизами. При подготовке магазина к запуску замените концепции фотографиями реальной продукции.

## Разработка

Требуется Node.js 22 или новее.

```sh
cd /workspace/site
npm ci --cache /tmp/site-npm-cache
npm run dev
```

Сборка: `npm run build`. Проверка сборки: `npm run preview`.

Для просмотра без сервера: `npm run export:html`, затем откройте `dist/WoodBase.html` в браузере. Этот файл содержит стили и JavaScript, использует системные шрифты и не требует подключения к сети. Сохранение корзины зависит от поддержки localStorage браузером для локальных файлов.

Корзина хранится в localStorage. Изображения уменьшаются до 600 пикселей и остаются в браузере. Состав заказа скачивается в JSON, включая загруженный рисунок. Запрос можно скачать с контактами и пожеланиями, либо открыть подготовленный текст в Telegram и самостоятельно выбрать чат и подтвердить отправку. При отсутствии публичного адреса мастерской используется меню Telegram «Поделиться». Рисунок не прикрепляется автоматически: передайте файл запроса или проекта отдельно. Контакты не сохраняются в корзине. Сервер, автоматическая отправка, оплата и доставка пока не подключены. Не храните в прототипе конфиденциальные изображения на общих устройствах.

Модели, цены, цвета и аксессуары задаются в `src/main.js`, стили — в `src/style.css` и `src/brand.css`. Внешние шрифты Google Fonts необязательны: предусмотрены системные замены.

## Фирменное оформление

Подготовленный PNG логотипа и три позы дятла находятся в `public/images/brand/`. Это обработанные генерацией версии по предоставленным изображениям бренда; перед выпуском сравните их с оригиналами. Логотип используется в шапке и подвале, маскот — в конструкторе и корзине. Конструктор имеет четыре доступных с клавиатуры шага: обложка, переплёт, цвет и дополнения. Итог и кнопка добавления остаются видимыми на каждом шаге.

Раздел деталей объединяет изображение альбома в руках, фактуру дерева и схемы переплётов. `public/images/in-hands.png` — сгенерированная визуализация, а не фотография реального изделия. Эти материалы включены и в автономный HTML. Уменьшение движения учитывает системную настройку `prefers-reduced-motion`.

Следующий этап: реальные данные мастерской и фото, сервер заказов и безопасное хранение загрузок, управление каталогом, проверка доступных интеграций Ozon и подключение согласованного способа оплаты и доставки.

## Конструктор и проекты

Масштаб, смещение и поворот рисунка сохраняются вместе с заказом. Чёрно-белый режим с порогом яркости показывает ориентировочный эскиз для гравировки; он не гарантирует результат лазерной обработки. Сохранение проекта — в этом браузере; скачивание JSON позволяет передать его близким и восстановить в конструкторе. Импорт проверяет формат и диапазоны параметров.

## Фотографии продукции

Исходные фотографии из переписки пока не доступны как файлы в рабочей среде. Не подменяйте их сгенерированными фотографиями. После получения JPG/PNG добавьте их в `public/images/products/` и укажите пути `/images/products/...` в `photos` соответствующего элемента `models` в `src/main.js`. Карточка товара уже поддерживает галерею. Для автономного HTML новые фотографии также нужно добавить в список в `scripts/export-html.mjs`.

Публичный Telegram username задаётся в `workshopTelegram` в `src/main.js`, без @. Это ссылка для покупателя, не бот и не серверная отправка. Никакие секреты в исходники не добавлять.

## Страница мастерской

Пункт «Наша мастерская» открывает отдельное представление по `#workshop`. Маршрут работает на обычном сайте и в автономном HTML, поддерживает прямое открытие, обновление и историю браузера. Главная и состояние конструктора сохраняются при переходах. Крупный маскот знакомит с брендом; раздел команды пока содержит пометку об ожидающих добавления фотографиях и историях, без вымышленных сотрудников.

## Проба графитового оформления

Первый экран, шапка и каталог используют графитовый фон, медный акцент и прямые крупные заголовки. Каталог — две колонки со смещением на широких экранах и одна на телефоне. Одобренное изображение главного альбома сохранено; каталог пока содержит эскизы, ожидающие исходных фотографий. Светлый конструктор и страница мастерской сохраняют прежнюю композицию.
