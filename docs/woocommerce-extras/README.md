# Платные дополнения WooCommerce: пакет для ручной установки

Статус: подготовлено, на VPS не установлено. Файлы действующей интеграции в этой ветке не изменялись. Автоматическое обновление витрины не устанавливает этот пакет.

Согласованные цены: упаковка 350 ₽, метрика 120 ₽, дополнительный блок листов 295 ₽, дополнительный блок уголков (5 листов) 120 ₽. Три позиции базового комплекта по-прежнему включены в стоимость альбома.

`server-pricing.patch` добавляет серверный перечень дополнений, их цены в `/product` (`extraPrices`) и расчёт доплаты в WooCommerce. Никакие суммы из браузера не используются. WooCommerce умножает рассчитанную цену единицы на количество товаров. Не меняются товары, база данных, схема хранения рисунков или настройки оплаты.

Порядок отдельной операционной проверки:

1. Сверить версию установленного плагина с исходным `integrations/woocommerce/plugin/woodbase.php` и сделать резервную копию файлов плагина.
2. Проверить патч в тестовом окружении: `git apply --check docs/woocommerce-extras/server-pricing.patch`; изучить diff. Применить патч к проверенной копии исходников, не к непроверенной другой версии плагина.
3. Отдельно установить обновлённый `woodbase.php` и новый `extras-pricing.php` в существующий плагин на VPS. Не запускать bootstrap, не переустанавливать WooCommerce и не заменять тома базы.
4. По процедуре `docs/github-vps-updates.md` согласовать новую версию backend. Не обходить проверку fingerprint и не менять его только ради успешной публикации.
5. Проверить API `/product`, добавление каждого дополнения, все четыре вместе, количество 2, удаление товара и оформление согласованным способом. При базовой цене 3540 ₽ все четыре дополнения дают 4425 ₽ за альбом; для двух — 8850 ₽. Убедиться, что подмена цены в запросе не влияет на сумму.
6. Для отката вернуть прежний `woodbase.php` из резервной копии. Сначала проверить корзины, уже содержащие дополнения: старая версия не должна пересчитать такой заказ по базовой цене. Нужен согласованный порядок обслуживания таких корзин, а не слепой откат.

До установки совместимого backend витрина показывает согласованные расценки, но блокирует онлайн-добавление платных дополнений с понятным сообщением. Сами альбомы без платных дополнений продолжают использовать прежний серверный сценарий. Это предотвращает заказ комплекта по заниженной базовой цене.

Проверки подготовленной копии: `php -l /путь/к/копии/woodbase.php` и `php docs/woocommerce-extras/check-pricing.php /путь/к/копии`. Это проверка PHP и чистого расчёта доплат, а не замена проверки заказа в работающем WooCommerce.
