# Платные дополнения WooCommerce

Серверный расчёт включён в плагин **0.3.0** вместе с новым оформлением заказа. На VPS пакет отдельно не устанавливался. Порядок проверки и ручной установки — в [документации оформления](../order-checkout.md).

Согласованные цены: упаковка 350 ₽, держатель для метрики 120 ₽, дополнительный блок листов 295 ₽, дополнительный блок уголков (5 листов) 120 ₽. Три позиции базового комплекта остаются включёнными в цену альбома.

Цены принадлежат серверу и публикуются в `/product.extraPrices`. В WooCommerce доплата прибавляется к актуальной каталожной цене единицы; количество учитывается отдельно. Все четыре дополнения дают 885 ₽: при цене альбома 3540 ₽ итог 4425 ₽, для двух — 8850 ₽. Суммы из браузера не используются.

`server-pricing.patch` сохранён как прежний пакет для версии 0.2.0. **Не применяйте его поверх 0.3.0:** изменения уже включены в исходники плагина.

Чистый расчёт можно проверить командой `php docs/woocommerce-extras/check-pricing.php integrations/woocommerce/plugin`. Проверка реального заказа, включая количество, выполняется `npm run test:checkout:server` в изолированном локальном WooCommerce. Это не проверка установки на VPS.

Пока действующий API не объявляет совместимые цены и список дополнений, витрина блокирует добавление платных опций с понятным сообщением. Базовые альбомы продолжают использовать прежний серверный сценарий.

Не откатывать плагин вслепую на версию, которая игнорирует дополнения: сначала проверить существующие корзины и заказы и согласовать их обслуживание.
